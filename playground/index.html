        03
    Docs
    
        
    The whole language on one page.
    
      
    
      
    
        
    Basics
      
          
    • Variable: badlo x = 10;
      • 
          
    • Print: dikhao(x);
      • 
          
    • Booleans: sahi_hai_be / jhuth
      • 
          
    • Null: khali
      • 
          
    • Comment: # yeh comment hai
      • 
          
    • Interpolation: "Hi {naam}!"
      • 
          
    • Input: padho("Naam? ")
      • 
        
    
        
    Operators
      
          
    • Math: + - * / % **
      • 
          
    • Compare: == != < > <= >=
      • 
          
    • Logic: aur ya nahin (or && || !)
      • 
          
    • Compound: += -= *= /= %=
      • 
          
    • Numbers: 42 3.14 .5 1e6 1_000
      • 
        
    
        
    Control flow
      
          
    • If: agar (c) { } warna { }
      • 
          
    • While: jabtak (c) { }
      • 
          
    • For: ginnati (badlo i = 0; i < 5; i += 1) { }
      • 
          
    • For-each: ke_liye (badlo x in list) { }
      • 
          
    • Switch: chuno (x) { case 1, 2: … warna_case: … }
      • 
          
    • Break / continue: bas; aage_badho;
      • 
        
    
        
    Functions
      
          
    • Define: kaam add(a, b) { wapas a + b; }
      • 
          
    • Defaults: kaam f(n, m = 2) { }
      • 
          
    • Varargs: kaam total(baaki nums) { }
      • 
          
    • Anonymous: kaam (x) { wapas x * 2; }
      • 
          
    • Use before defining. Functions can be nested.
      • 
        
    
        
    Data
      
          
    • List: [1, 2, 3] with push pop sort slice
      • 
          
    • Dict: {"key": "value"} with keys values hatao
      • 
          
    • Record: dhacha Vyakti { naam, umar };
      • 
          
    • Create: Vyakti { naam: "A", umar: 9 }
      • 
          
    • Method: kaam Vyakti.hi() { wapas yeh.naam; }
      • 
        
    
        
    Errors & modules
      
          
    • Catch: pakdo { } chhoddo (err) { }
      • 
          
    • Catches runtime errors too, e.g. 1 / 0
      • 
          
    • Throw: chhoddo("message");
      • 
          
    • Import: lao "utils.aak"; (CLI)
      • 
          
    • Builtins: length push pop rakho nikalo hatao map filter reduce random_number current_time abs floor ceil upper lower join split prakar shabdme sankhya range keys values contains sort reverse slice replace trim find min_val max_val round_val padho
      • 
        
    
      
    
      
    
        
    Run it on your computer
    
        
    cargo install --git https://github.com/anonymousAAK/adarshLang adarshlang
adarsh hello.aak          # run a program
adarsh                    # REPL
adarsh build hello.aak    # make a standalone executable
