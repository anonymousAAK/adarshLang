        04
      Docs
      
        
      The essentials. Everything else: full reference.
      
      
      
      
      
        
      Basics
        
          
      • Variable: badlo x = 10; · constant: pakka PI2 = 6.28;
        • 
          
      • Print: dikhao("Hi {naam}!"); · format: "{x:.2}"
        • 
          
      • sahi_hai_be / jhuth / khali
        • 
          
      • Strings: """multi-line""", raw r"C:\path"
        • 
          
      • Input: padho("Naam? ")
        • 
        
      
        
      Operators
        
          
      • + - * / // % ** · == != < > <= >=
        • 
          
      • aur ya nahin · 0 < x < 10 · x in xs
        • 
          
      • x hai number · user?.naam ?? "anjaan"
        • 
          
      • agar (c) a warna b · ranges 1..10
        • 
        
      
        
      Control flow
        
          
      • agar / warna, jabtak, karo { } jabtak (c);
        • 
          
      • ginnati (badlo i = 0; i < 5; i += 1)
        • 
          
      • ke_liye (badlo i, x in xs)
        • 
          
      • chuno with case 1..5:, case [a, ...rest]:, agar guards
        • 
        
      
        
      Functions
        
          
      • kaam add(a, b = 0) { wapas a + b; }
        • 
          
      • Lambdas x => x * 2, spread f(...xs), named f(b: 1)
        • 
          
      • Dot-calls: xs.sort(by: f), naam.upper()
        • 
          
      • Generators with dete_raho
        • 
        
      
        
      Data
        
          
      • Lists, dicts, tuples (1, 2), sets set([1, 2])
        • 
          
      • Slices xs[1:3], destructuring badlo [a, b] = xs;
        • 
          
      • dhacha Student : Vyakti { roll }; with methods
        • 
          
      • Enums: vikalp Rang { Laal, Hara };
        • 
        
      
        
      Errors & more
        
          
      • pakdo { } chhoddo (e: Type) { } aakhir { }
        • 
          
      • Tests: jaancho(x == 4, "msg");
        • 
          
      • Drawing: kachhua.aage(100); kachhua.daayen(90);
        • 
          
      • Builtins: map filter reduce sort sum json_padho tareekh rupaye … (107)
        • 
        
      
      
      
      
      
        
      Run it on your computer
      
        
      cargo install --git https://github.com/anonymousAAK/adarshLang adarshlang
adarsh hello.aak          # run a program
adarsh test               # run *_test.aak tests
adarsh python hello.aak   # see it in Python
adarsh build hello.aak    # make a standalone executable
